# Fonts for staff tools

`Vazirmatn-Bold.ttf` (version 33.003) by Saber Rastikerdar, from
https://github.com/rastikerdar/vazirmatn, under the SIL Open Font License 1.1
(see `OFL.txt`). Only `tools/staff/gen_signs.py` uses it, to print the
Persian names on the city's signs. The generated PNGs are committed, so
students never need the font.
