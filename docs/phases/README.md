# Phases

The project is built in three phases on the same plot. Each phase has its
own document, published in this folder when the phase starts.

| Phase | Topic | Document |
|---|---|---|
| 1 | Modeling with transformations: geometry, translation, rotation, scaling, composition, geometry reuse | [Build the Plot](phase1-build-the-plot.pdf) |
| 2 | Animation: time-based motion, pivots, Bézier motion, easing | to be published |
| 3 | Lighting and texture: normals, lighting and materials, textures | to be published |
